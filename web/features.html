Features

Every way a stream dies, covered.

Twelve features, one goal: the audience never watches a dead stream. Each card says how far it has been proven.

Crash shield.

If OBS crashes, every platform keeps receiving your Be right back screen while OBS restarts. Keel resumes the broadcast by itself. The stream never ends on viewers.

Built, tested in code

Backup encoder, automatic failover.

Every server takes a second phone, app or Belabox. When the primary drops, viewers stay live on the backup instead of seeing BRB.

Built, tested in code

Switching that understands SRT.

Keel reads packet loss, late packets and round trip time from the link, not only bitrate. A feed at full bitrate that is breaking up still counts as weak.

Built, tested in code

Multistream, isolated.

Twitch, Kick, YouTube and any RTMP or SRT target at once. Each destination reconnects on its own, so one platform having a bad minute never touches the others.

Built, tested in code

Broadcast auto-recover.

If the output stops without anyone pressing stop, Keel restarts it with a short backoff and tells the crew.

Built, tested in code

Rules you can change live.

Thresholds, timings and SRT limits change from the dashboard mid-stream. No restart, no support ticket.

Built, tested in code

Crew alerts.

Drops, recoveries, failovers, platform reconnects and crash shield events go to Discord or Slack, throttled so a flapping link cannot spam the channel.

Built, tested in code

Moderator access in seconds.

A second token lets mods switch scenes and sources. They cannot stop the stream or change settings.

Built, tested in code

Phone setup by QR.

Every ingest address has a copy button and a QR code. No typing stream keys on a phone keyboard.

Built

Reliability record.

Drops held, failovers, time on BRB, platform reconnects and crash shield time, logged per stream. Proof you can show a sponsor.

Built, tested in code

Server stops when you do.

Idle shutdown and per-minute metering, so a streamer never pays for an empty server.

Built, tested in code

Companion app.

State, link quality, destinations and controls on your phone while you walk.

For the crew

Run it like a broadcast.

Dashboard. Signal, link quality, what viewers see, destinations, sources, rules and a full event log, live. Built to read on a phone in sunlight.
Twitch chat commands. !status, !live, !low, !brb, !auto, !source backup, !start, !stop. Stop is limited to the broadcaster.
Prometheus metrics. Bitrate, RTT, loss, drops, failovers, destination health, crash shield and restarts, ready for Grafana.
Security. Tokens never sit in URLs (one-time tickets for the live feed), stream keys are redacted from every log and screen, HTTPS with automatic certificates, the plain HTTP port locked to the server.
