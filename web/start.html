Self-host guide

One command to your first stream.

You need a fresh Ubuntu server with a public IP and a stream key for at least one platform. No domain needed: Keel can use a free sslip.io name with a real certificate.

1

Get the code on the server.

git clone https://github.com/vishhhh999/keel.git
cd keel
2

Run the installer.

KEEL_DESTINATIONS='Twitch=rtmp://live.twitch.tv/app/live_xxx;Kick=rtmps://.../app/sk_xxx' \
  bash deploy/install.sh

It installs Docker, generates every secret, opens the firewall, starts the stack with HTTPS, and prints your dashboard address, admin token, moderator token and phone addresses. Add KEEL_NOTIFY_WEBHOOK for Discord or Slack alerts.

3

Point your phones at it.

Primary phone on the primary SRT address, backup phone on the backup address. Scan the QR codes from the dashboard. See phone setup.

4

Go live.

Press Go live on the dashboard. Walk into a dead zone on purpose once, so you know what your viewers see.

Full reference with every setting, the manual Docker route, GPU notes and troubleshooting: README.md and docs/ in the repo.

The signal moves. The stream holds. A reliability layer for people who stream from the street.
