Get it running

Thirty minutes to your first stream.

You need a Linux server with a public IP, Docker, and a stream key for one platform.

1

Get the code.

git clone <your keel repo>
cd keel/stack
cp .env.example .env
2

Fill in .env.

Set your admin token, your platform stream key, and your public hostname.

3

Start it.

docker compose up -d
4

Point your phone at it.

In your IRL streaming app set the output to srt://your-host:8890 with the stream id from the README. Open the dashboard to watch the state.

Full guide with firewall ports, TLS and troubleshooting: README.md and docs/ in the repo.

The signal moves. The stream holds.
